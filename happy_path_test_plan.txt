LAB 1 — AGENT LOOP
==================================================

**1. Test Case Name:** Interactive Clarify → Plan → Revise Loop
**2. Purpose:** Demonstrate the conversational state machine where the agent clarifies vague requests, generates a plan, and revises it based on human feedback.
**3. Exact data/input:**
*   Message 1: "I want to get a software job"
*   Message 2: "Computer Science, I know Python"
*   Message 3: "Please add a stronger focus on System Design"
**4. Exact UI action:** Go to "Agent Loop (Lab 1)" tab. Use the chat interface.
**5. Expected result:** The agent responds conversationally, transitioning internal states (`clarifying` → `planning` → `revising`).
**6. What I should observe:**
*   *After Msg 1:* Agent asks for branch/skills.
*   *After Msg 2:* Agent outputs a structured placement readiness plan.
*   *After Msg 3:* Agent acknowledges feedback and outputs an updated plan containing "System Design".
**7. PASS condition:** The agent successfully incorporates the revision without losing the context of the previous plan.
**8. Screenshot/evidence:** Capture the chat window showing the final revised plan bubble.

LAB 8 — PARALLEL SWARM
==================================================

**1. Test Case Name:** Bounded Parallel Fan-Out / Fan-In
**2. Purpose:** Prove the `BatchRunner` successfully orchestrates multiple node graphs concurrently, isolating state and merging the results.
**3. Exact data/input:** `student_A, student_B, student_C, student_D`. Target Role: `Software Engineer`.

**5. Expected result:** The batch initiates, spawns 4 concurrent threads via `ThreadPoolExecutor`, processes them, and returns a single merged `BatchResult`.

**7. PASS condition:** All 4 students are processed concurrently without data cross-contamination, successfully fanning in to a single payload.
**8. Screenshot/evidence:** Capture the Swarm Status dashboard showing 4 successful executions and the populated Metrics box.
